# Kaaram

A recipe app for Telugu and South Indian food, built with SwiftUI for iOS.

## About

Kaaram (కారం — "spice" in Telugu) is a curated collection of authentic Telugu and South Indian recipes, from everyday staples like pappu and pulihora to festive favorites like pulusu, vada, and biryani.

## Status

Early development — initial Xcode project scaffolding.

## Requirements

- Xcode 15+
- iOS 17+
- Swift 5.9+

## Getting Started

```bash
git clone https://github.com/saigorupati/kaaram.git
cd kaaram
open kaaram.xcodeproj
```

Build and run in Xcode (⌘R).

## Project Structure

- `kaaram/` — App source (SwiftUI views, models, assets)
- `kaaramTests/` — Unit tests
- `kaaramUITests/` — UI tests
